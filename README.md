# Dashboard interactivo para el ajuste de modelos heurísticos de crecimiento y cuantificación de incertidumbre mediante técnicas bootstrap

## Descripción

Este repositorio contiene el desarrollo de la tesina de licenciatura orientada a la construcción de un **dashboard interactivo de acceso libre** para el ajuste de modelos heurísticos de crecimiento, la estimación de parámetros mediante regresión no lineal y la cuantificación de incertidumbre a través de bootstrap paramétrico. Aquí se almacenan notas, versiones de código, implementaciones, y los escritos correspondientes a las distintas secciones de la tesina.

### Cómo usar este repositorio
Este es un repositorio de trabajo académico individual; no está pensado para contribuciones externas. Cada carpeta refleja una etapa o componente del proceso de tesis, y el historial de commits sirve como registro del avance
